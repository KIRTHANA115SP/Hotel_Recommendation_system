# 🏨 Hotel Recommendation System

## 📖 Description
The **Hotel Suggester Management System** in *Vellore* helps travelers find the perfect hotel by analyzing their preferences such as **budget**, **food options**, or **amenities** like **spas** and **gyms**.  
It suggests hotels based on the user's **mood**, notifies them of **price drops** and **special deals**, and provides easy access to **hotel routes**.  
The system also promotes **knowledge-sharing** by collecting feedback that helps hotels improve their services and assists users in making informed decisions.

---

## 💡 Features
- 🖥️ **User-friendly GUI** built with *Java Swing*  
- 🔐 **Secure data handling** with *Oracle Database*  
- 📋 **Modules** for service requests, feedback, and history tracking  
- 🎨 **Clean and intuitive interface** for seamless navigation  
- ⚙️ **Efficient hotel service management** with organized workflows  
- 💬 **Personalized recommendations** based on user preferences and moods

## 🧩 System Modules
1. **View Personal Details** – Displays user profile and booking data.  
2. **Request Service** – Allows users to request hotel services or amenities.  
3. **Service History** – Keeps track of previous bookings and interactions.  
4. **Educational Resources** – Provides guides for travelers and hotel information.  
5. **Feedback** – Users can rate and review hotels.
6. **Add or delete hotels** – admins can add new hotels.
7. **Logout** – Ensures secure session handling.

---

## 🚀 How It Works
1. The user logs in to the system using their credentials.  
2. They enter their travel preferences and budget.  
3. The system analyzes the data and suggests suitable hotels.  
4. Users can explore routes, check amenities, and view special offers.  
5. Feedback collected helps refine future recommendations.
